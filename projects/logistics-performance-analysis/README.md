Logistics Performance Analysis

Project Overview

This project explores logistics data using Microsoft Excel to demonstrate practical data analysis, reporting, and business problem-solving skills.

The project was completed as part of a capstone project through TS Academy.

Objectives

* Explore the logistics dataset.
* Identify relevant performance indicators.
* Analyse available data to identify patterns and trends.
* Present findings that could support logistics and operational decisions.

Tools Used

* Microsoft Excel

Project Process

1. Review the dataset and understand its structure.
2. Inspect and prepare the data for analysis.
3. Analyse the available metrics.
4. Summarise findings and business implications.
